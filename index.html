KIẾN TRÚC VẬN HÀNH

Mô Hình Triển Khai Hệ Thống

1. Source Control & Versioning

Quản lý mã nguồn trên Git Repository. Phân chia rõ ràng các nhánh main (Production) và develop (Staging).

2. Continuous Integration (CI)

GitHub Actions tự động kích hoạt khi có commit/pull request: Kiểm tra cú pháp, chạy unit test và build image Docker.

3. Continuous Deployment (CD)

Tự động push image lên Docker Hub / GitHub Container Registry và cập nhật lên máy chủ Production mà không gây gián đoạn (Zero Downtime).

4. Reverse Proxy & Bảo mật với Nginx

Nginx đóng vai trò Load Balancer, nén Gzip, cache tĩnh và quản lý chứng chỉ SSL tự động gia hạn.
